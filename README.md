### 🚀 Featured Projects

**🔹 Multi-Agent System for Scientific Text Simplification**

Multi-agent system based on **LLMs and LangGraph** for the automatic simplification of biomedical scientific texts, developed as part of my **Master's Thesis** and within the SimpleText evaluation task.

**🔹 GraphRAG for Zoology**

Question-answering system combining **Knowledge Graphs, Neo4j, Text2Cypher, vector search and full-text search**, together with reranking and specialized agents.

**🔹 Semantic Search for Artworks**

Semantic search system using **Google Gemini, BGE-M3 embeddings, FAISS and ChromaDB**, with a REST API developed using FastAPI and a React web interface.

**🔹 Explainable AI**

Project focused on **Machine Learning interpretability and explainability**, exploring techniques such as **LIME and SHAP**.
